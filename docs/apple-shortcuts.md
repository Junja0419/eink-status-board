# Apple 단축어 연동 가이드

iPhone·iPad·Mac의 **단축어(Shortcuts)** 앱에서 원탭으로 E-ink 화면을 바꾸는 방법입니다.

## 왜 "마스터 단축어" 방식인가

과거에는 서버가 `.shortcut` 파일을 생성해 내려주는 방식을 시도했지만,
iOS 15+ / macOS Monterey+ 부터는 **서명되지 않은 단축어 파일 설치가 OS 레벨에서 차단**됩니다.

대신 아래처럼 동작하는 단축어를 **딱 하나만** 직접 만들어 두면 됩니다.

```
GET  /api/shortcuts/names      →  프리셋 이름 목록 (줄바꿈 구분 텍스트)
      ↓ 텍스트 분리 → 목록에서 선택
POST /api/shortcuts/activate   →  {"name": "<선택한 이름>"}
```

프리셋을 추가·삭제해도 단축어를 수정할 필요가 없습니다. 목록은 매번 서버에서 받아옵니다.
이름 목록을 JSON이 아닌 **일반 텍스트**로 받는 이유는, 단축어 앱의 JSON 파싱이 이모지가 섞인 문자열에서 불안정하기 때문입니다.

## 만들기 (약 1분)

Admin 페이지 하단의 **서버 설정**에 외부 URL을 저장해 두면, 같은 페이지의 가이드 카드에 아래 주소가 자동으로 채워집니다.

| # | 동작 | 설정 |
|---|------|------|
| 1 | **URL** | `http://<서버주소>:5000/api/shortcuts/names` |
| 2 | **URL의 콘텐츠 가져오기** | 기본값(GET) |
| 3 | **텍스트 분리** | 분리 기준: **새로운 줄** |
| 4 | **목록에서 선택** | 입력: 3번 결과 |
| 5 | **URL** | `http://<서버주소>:5000/api/shortcuts/activate` |
| 6 | **URL의 콘텐츠 가져오기** | 방법: **POST** · 요청 본문: **JSON** · 필드 추가(텍스트) → 키 `name`, 값 **선택한 항목** |

단축어 이름은 "E-ink 갱신"처럼 짓고, 제어 센터·위젯·메뉴 막대·Siri 어디에 붙여도 됩니다.

## 특정 프리셋 전용 단축어

메뉴 선택 없이 바로 하나를 적용하려면 5·6번 동작만 넣고 `name`에 프리셋 이름을 고정합니다.
"회의 중" 단축어를 캘린더 자동화(회의 시작 시 실행)에 연결하는 식으로 활용할 수 있습니다.

## 문제 해결

| 증상 | 원인 / 조치 |
|------|-------------|
| 목록이 비어 있음 | Admin에서 프리셋이 하나도 없거나 URL이 잘못됨. 브라우저에서 1번 URL을 직접 열어 확인 |
| `404 프리셋을 찾을 수 없습니다` | 이름이 서버의 것과 다름. 앞뒤 공백은 서버가 무시하지만 이모지·띄어쓰기는 정확히 같아야 함 |
| 단축어가 "안전하지 않은 연결" 경고 | `http://` 이기 때문. 설정 → 단축어 → 고급에서 허용하거나, [HTTPS 적용](deploy-gcp.md#6-보안-강화-권장) |
| 적용은 됐는데 화면이 안 바뀜 | `clients_notified`가 0이면 ESP32가 서버에 연결되어 있지 않음. Admin 상단의 연결 표시 확인 |

## curl로 같은 동작 재현

```bash
curl http://<서버주소>:5000/api/shortcuts/names

curl -X POST http://<서버주소>:5000/api/shortcuts/activate \
  -H "Content-Type: application/json" \
  -d '{"name": "회의 중"}'
```
