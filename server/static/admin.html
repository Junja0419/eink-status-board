아직 등록된 상태 프리셋이 없습니다.

🍎 제어 센터용 "단축어" 만드는 법 (초간단/오류없음)

단축어 앱에서 "E-ink 갱신"이라는 단축어를 하나만 직접 만들어두면, 제어 센터에서 클릭 한 번에 모든 잉크 화면을 고를 수 있습니다!

  1. 단축어 앱을 열고 새 단축어를 만듭니다.
  2. URL 동작을 추가하고 아래 주소를 넣습니다.
    https://<도메인>/api/shortcuts/names
  3. URL의 콘텐츠 가져오기 동작을 이어서 추가하고, 화살표(더 보기)를 눌러 헤더에서 새로운 헤더 추가를 누릅니다. 키(Key)에는 X-API-Key를 입력하고, 텍스트(Text)에는 서버 .env 파일의 API_KEY 값을 붙여넣습니다.
  4. 텍스트 분리 동작을 이어서 추가합니다. (기준을 새로운 줄로 설정하세요)
  5. 목록에서 선택 동작을 이어서 추가합니다. (방금 분리된 텍스트 목록이 깔끔하게 뜹니다)
  6. URL 동작을 하나 더 추가하고 아래 주소를 넣습니다.
    https://<도메인>/api/shortcuts/activate
  7. URL의 콘텐츠 가져오기 동작을 마지막으로 추가하고, 화살표(더 보기)를 눌러 방법을 POST로 바꿉니다. 3번과 같이 X-API-Key 헤더를 추가하고 같은 API_KEY 값을 넣습니다.
  8. 바로 아래 요청 본문 (Request Body)을 JSON으로 설정하고, 새로운 필드 추가 (텍스트)를 눌러 키(Key)에는 name을 입력하고, 텍스트(Text)에는 '선택한 항목' 변수를 넣습니다.

API_KEY는 서버 .env 파일에 설정한 값입니다. 보안을 위해 이 페이지에서는 보여주지 않으며, 단축어용 주소(/api/shortcuts/*)에서만 쓸 수 있습니다.

이제 이모지가 들어간 이름도, 여러 개의 프리셋도 100% 오류 없이 완벽하게 작동합니다!
